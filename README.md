# Erotic Pole Dancer Tool

Pole clearance calculator for utility pole attachment work (NESC and Kentucky coop spacing rules).

Live: https://pole-clearance-tool.vercel.app

- `PoleClearance.html` is the whole app (one file, also runs offline by opening it directly).
- `web/build.py` turns it into the hosted site (adds the install manifest, icons and offline support) in `web/public/`.
- Vercel runs the build on every push to `main`.
